# High Level Design:Online Judge(MERN Stack)
--- 
## 1.Problem Statement
A coding contest is a competetive event where participants solve coding problems within a specified timefram.Participants submit solutiongs,which are evaluated against hidden test cases,and scores are assigned based on correctness.
This system aims to build an **Online Judge(OJ)** platform that :
-Allows users to participate in contests 
-Evaluates code submissions
-Displays scores/leaderboards
Examples of similar platforms:Leetcode,CodeChef.
